## Evidence limits

* These recordings support public documentation and bounded first-run UI observations. No ingested service, successful Debug Session, captured local value or populated source editor is demonstrated.
* GitHub installation and permission screens are pre-install previews. During the footage in this archive, the GitHub App had not yet been installed; the later approved continuation is separate. The custom installation draft shown here was canceled.
* The attempted capture restart around 02:33 UTC failed. GitHub account creation and initial authenticated welcome in that gap have screenshot-only evidence. They are not reconstructed as video.
* Source 06 contains only recorder/desktop preparation. The browser window did not become available, so the intended isolated signed-out check did not run.
* Masks and crops can hide adjacent UI, including a header label or the bottom edge of a modal Start button. Hidden areas are not evidence of a missing or broken product control. The edited highlights provide cleaner views of selected controls.
